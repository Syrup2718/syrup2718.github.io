這個網站本身就是專案二！使用 Astro 靜態站點生成器建構。

## 特色
- 極簡 + 少女風設計
- Setofont 可變字體
- MDX 支援，可在文章中寫 React 元件
- 自動生成 RSS 與 Sitemap
- 部署於 GitHub Pages
- 陪伴天數即時計算
