使用 Vue 3 + Tailwind CSS 開發的天氣小工具。

## 規劃功能
- 以 IP 定位自動顯示當地天氣
- 7 天預報
- 空氣品質指數 (AQI)
- 支援多城市切換
- 深色模式
- 可嵌入桌面或網頁

目前正在開發中，敬請期待。
