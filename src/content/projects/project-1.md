這是一個用 React + TypeScript 建構的待辦清單應用。

## 功能
- 新增、編輯、刪除待辦事項
- 標記完成 / 未完成
- 分類標籤（工作、生活、購物...）
- 資料儲存在 LocalStorage，重整不會消失
- 響應式設計，手機桌面都好用

## 技術棧
- React 18
- TypeScript
- Vite
- CSS Modules
